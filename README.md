# AsterMech Corp

Cinematic website for AsterMech Corp, an independent software studio.

## Live site

Open the GitHub Pages URL after the first deploy:

**https://robbb9000.github.io/astermech-corp/**

On a computer, scroll through the hangar film. The mech assembles as you scroll.

## Local

```bash
npm install
npm run dev
```

The full React app lives in `src/`. The Pages build is the static film in `docs/`.
